# cprimozic.net

Personal website and blog for me, Casey Primozic.

Built with SvelteKit, Svelte 5, and Vite. Blog posts are Markdown rendered through remark/rehype with Shiki for syntax highlighting and KaTeX for math, images are processed with sharp, the notes subsite is built with Hugo, and the background animation is Rust compiled to WebAssembly.
